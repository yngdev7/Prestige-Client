## What is Prestige Client?

**Prestige Client** is a simple **Minecraft PvP Client** mod built for Minecraft players who want a lightweight client utility for Fabric. This repository is the official home for the latest **Minecraft PvP Client** release.

Whether you play alone or with friends, **Minecraft PvP Client** gives you a fast way to use the client with a clean command and keybind setup for supported Fabric versions.

## Minecraft PvP Client Installation Guide

### Requirements

- Minecraft **1.21.11**
- **Fabric Loader** + **Fabric API**
- Java 17 or higher

### Steps

1. Go to the **[Releases](../../releases)** tab on this repo
2. Download the latest `Prestige-Client-1.21.11.jar`
3. Place the JAR in your `.minecraft/mods` folder (Fabric)
4. Launch Minecraft with **Fabric Loader** installed
